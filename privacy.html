Privacy Policy – wimode agent

Last updated: October 29, 2026

wimode agent is a personal automation tool. It is used only by its owner to publish the owner's own videos to the owner's own YouTube channel and Instagram account.

What data is accessed

With the owner's consent through Google OAuth, the tool uses the YouTube Data API to upload videos, set titles, descriptions, tags and thumbnails, and post a comment on the uploaded video. It does not read, collect or store data about any other person.

Where data is stored

Access tokens are stored only on the owner's own computer. No data is sent to any server other than Google (YouTube) and Meta (Instagram) APIs. Nothing is sold, shared or used for advertising.

Google API Services

The use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.
